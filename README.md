## What this tool does

The ratatui-themekit provides a visual theme system for terminal applications. Many programs running in your command prompt look plain or hard to read. This software applies modern color schemes to those tools. It includes nine built-in themes like Catppuccin, Dracula, and Nord. It also respects your system settings if you prefer to hide colors.

## 💻 System requirements

Your computer needs to meet these basic standards to run this software:

*   Operating System: Windows 10 or Windows 11.
*   Memory: At least 256 MB of available RAM.
*   Storage: 50 MB of free disk space.
*   Terminal: Windows Terminal or the standard Command Prompt.

## 🎨 Choose your theme

The program shows a list of nine themes when it starts. Use the arrow keys on your keyboard to highlight a selection. Press the Enter key to apply a new look. The colors will update in your terminal window immediately. 

The available themes include:

*   Catppuccin: A soft, pastel color palette.
*   Dracula: A dark, high-contrast theme.
*   Nord: A cool, blue-toned Arctic scheme.
*   System Default: The standard colors for your terminal.

## 🚫 Using NO_COLOR mode

Some users prefer text without color tags. This helps with accessibility or printing logs to paper. You can toggle this mode by pressing the N key inside the main menu. The software will strip all color information from your terminal output while this mode stays active. Press N again to return to your chosen color theme.

## 🛠 Troubleshooting common issues

If the software does not work as expected, check these common items:

*   Does the terminal window close instantly? Ensure you have the latest updates installed for Windows.
*   Are the colors blurry? Check your Windows Terminal settings and ensure you have enabled ClearType text.
*   Does the program freeze? Close the window and restart the .exe file. This resets the temporary color configuration file.
*   Can you find the configuration file? The application creates a file named config.toml in your home folder. You can delete this file to reset the application to its original state.
